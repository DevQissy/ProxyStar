# ProxyStar

**Discover better connections. Test. Connect.**

An Android app for discovering proxy servers, checking connectivity, and sorting available connections by live network quality.

## Overview

ProxyStar helps you find and evaluate proxy connections using sources configured by the project. It checks server availability and measures latency from your current network, helping you compare connections instead of relying on a static list.

## Features

- **Proxy discovery** — collects proxy entries from configured public sources.
- **Connectivity checks** — checks whether discovered servers are reachable.
- **Live ping** — measures latency from your current network.
- **Quality-based sorting** — organizes results using connection measurements.
- **Network-aware recommendations** — helps compare connections across regions, operators, and changing network conditions.
- **Large server list** — designed to evaluate more than 1,000 selected entries, depending on the available source data.
- **Telegram updates** — follow the channel for project news and automated reports.

> Ping and reachability results are snapshots of the network at the time of testing. They can change by location, operator, routing, server load, and time. A successful check does not guarantee that every app or service will work through a proxy.

## Privacy and network behavior

ProxyStar performs network checks to evaluate proxy availability and latency. Network results depend on the device's active connection and the remote servers being tested.

Do not assume that using a proxy automatically encrypts all traffic, makes you anonymous, or protects information sent through an untrusted proxy. Avoid sending passwords, payment details, or other sensitive information through proxy servers you do not trust.

For the app's actual data handling, review the current implementation and any privacy information provided with the release. This README does not replace a full technical or privacy audit.
