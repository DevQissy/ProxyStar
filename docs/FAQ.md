# Frequently Asked Questions

## What is ProxyStar?

ProxyStar is an Android application that helps users discover public proxy servers, check connectivity, measure latency, and sort available servers by connection quality.

## Why does Android show "App blocked to protect your device"?

ProxyStar is distributed outside Google Play. Android and Google Play Protect apply security checks to apps installed from external sources, and some installations may be warned about or blocked.

However, this message does not establish the exact reason a particular APK was blocked. It also does not prove that an app is either safe or malicious.

For more information, see Google's documentation:

- [Google Play Protect — Android Enterprise Help](https://support.google.com/work/android/answer/15162069)
- [Download apps to your Android device](https://support.google.com/android/answer/9457058)
- [Distributing apps outside Google Play](https://developer.android.com/distribute/marketing-tools/alternative-distribution)

## How can I install ProxyStar if Android displays a warning?

**Proceed only if you trust the source and have independently verified the APK.**

1. Download the APK from the official ProxyStar GitHub Releases page.
2. Check that the downloaded filename and release version match the published release.
3. If Android displays a warning, read the entire message carefully.
4. If the screen offers **More details** and then **Install anyway**, those options may allow you to continue. They may not be available on every device or for every warning.
5. If installation remains blocked, or the warning identifies a specific security threat, cancel the installation rather than trying to bypass the protection.

Do not disable Google Play Protect just to install an app. If you are unsure about the warning, do not proceed.

## Is ProxyStar malware-free?

ProxyStar is distributed by its developer, but distribution outside Google Play does not itself establish that an APK is safe. No claim of independent security certification is made here.

Users should obtain the APK from the official release page, verify its integrity where a checksum is provided, and review any security warning before installing it.

## Why do server speeds and availability change?

Proxy performance depends on several factors, including the proxy server, your internet provider, routing, congestion, location, and temporary network conditions. A server that performs well now may perform poorly later.

## Does a successful ping guarantee that a proxy will work?

No. A latency or connectivity test is only an indicator. It does not guarantee that every connection, website, or application will work through that proxy.
